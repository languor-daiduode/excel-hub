# 项目简介 / Project Description

## 中文版

Excel Hub 是一个本机运行的 Excel 增量汇总与可视化工具。它只重读新增或修改过的表格，通过统一的“产品 Key”关联不同文件，并使用 DuckDB、Parquet 和 Streamlit 生成趋势、对比、排行、占比与明细看板。它适合持续追加 Excel、需要统一 Key 汇总且不希望在云端处理数据的场景。

## English Version

Excel Hub is a local-first toolkit for incrementally aggregating Excel files into an interactive dashboard. It reprocesses only new or modified spreadsheets, links records through a unified product key, and uses DuckDB, Parquet, and Streamlit to produce trend, comparison, ranking, proportion, and detail views. It is designed for continuously updated Excel files, unified-key reporting, and privacy-sensitive local workflows.
